This is the repository that manages SKK development.
SKK is the Japanese input method.

I'm using skk in Windows (CorvusSKK), linux (ibus-skk) and in vim (skkeleton). But now `denops`, that are base of skkeleton, may be end (deno is maintained by community but not by `official`). And also now we use the separated data, but I want to use the same input engine in every machine. I also consider developping skk input in Android smart phone.

This folder contains each project related in this desire, and docs that cross over each project.
